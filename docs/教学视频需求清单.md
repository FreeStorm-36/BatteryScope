# 教学科普视频 · 需求清单与获取标准

> 编制日期：2026-10-15
> 对应代码：`src/data/videos.js`（全站唯一视频清单）｜`src/components/VideoSlot.vue`（视频位组件）
> 用途：本文档既是**给你的找片/自录标准**，也是交付时的**素材登记表**。

---

## 0. 先说结论

**我建议走"本地自托管"路线，而不是嵌入 B 站等平台的播放器。** 原因有四条，都是硬的：

| # | 问题 | 说明 |
|---|---|---|
| 1 | **断网就白屏** | 答辩现场、评审电脑、科技馆展项都可能没有网络或屏蔽外链。嵌入播放器一断网就是一个空白框。 |
| 2 | **版权与原创性** | 竞赛规则要求"涉及第三方素材应合法使用并注明来源"。整段嵌入他人视频，评审会直接质疑作品的原创性份额——（七）赛道的作品要求第 2 条还专门写着"不得以技术展示替代必要的教育或科普内容设计"。 |
| 3 | **无法保证科学性** | 这个项目最硬的资产就是"每处内容都有依据"。网上的科普视频我无法逐帧核对，万一里面讲错一处（比如"电子穿过隔膜"），反而成了扣分点。 |
| 4 | **观感被破坏** | 平台播放器自带推荐、弹幕、水印、片头广告，和本作品统一的深蓝科技调完全冲突。 |

**所以正确做法是：把视频文件放到本地，由页面的 `<video>` 标签播放。** 三条获取路径：

| 路径 | 版权 | 离线可用 | 与页面的一致性 | 推荐度 |
|---|---|---|---|---|
| **A. 自己录制 / 自制动画** | 完全自有 | ✓ | 最高 | ★★★★★ |
| **B. 用 CC / 公有领域素材二次剪辑** | 署名即可用 | ✓ | 中高 | ★★★★ |
| **C. 平台播放器嵌入** | 有风险 | ✗ | 差 | ★★（仅可作"延伸观看"） |

**最小可行方案**：如果时间紧，优先做 **A** 里的「页面录屏 + 口播」——用本作品自己当素材，录制成本最低，而且天然和页面口径一致（不可能讲错）。第 05、06、07 章的三条视频都可以这么干。

## 0.1 优先级：不必八条全做（重要）

**八条全部做完不是最优解。** 评审看的是"教育设计的完整性"，不是"视频数量"。

判断标准只有一条：**这条视频是不是在复读动画已经讲清的内容？**
- 如果是 → 做了等于自己稀释自己，还会让人怀疑"是不是动画不够用才塞视频"；
- 如果不是（真实实拍 / 权威影像 / 讲自己的算法）→ 值得做。

按这条标准，八条分三级（代码里 `src/data/videos.js` 的 `priority` 字段，开发态占位卡会显示）：

| 优先级 | 视频位 | 为什么 |
|---|---|---|
| **必做** | `ch04-plating` | NASA/NREL 有真实同步辐射 X 射线影像，录下了电芯内部热失控全过程。**全网独此一家，别的科普号做不出来**，也是"动画示意"无法替代的现实证据 |
| **必做** | `ch07-holdout` | 讲的是本团队自己的算法与结果，网上不存在对应内容，**只能自己录**。同时是"学生实质性贡献"的直接证据 |
| **必做** | `ch02-teardown` | 真实剖切实拍能补上"实物长什么样"，这是程序化三维模型给不了的一层 |
| 建议 | `ch03-cccv` | 页面已有充电曲线，录屏+口播成本极低 |
| 建议 | `ch06-methods` | 页面已有三条路线对比图，录屏成本低 |
| 建议 | `ch05-nasa` | 参数细节网上找不到对得上的，只能自己录；直接影响"数据可信度"的说服力 |
| 可选 | `ch03-ion-path` | 本页三维动画本身就是这条内容，且能交互。**再放同题视频属重复，建议留空** |
| 可选 | `ch04-sei` | 机制卡与三维损伤演示已覆盖，把时间留给同章的析锂那条 |

> **留空是安全选项，不是欠账。** 未就绪的视频位在正式构建里完全不渲染——页面上不会出现空白框、占位符或"待接入"字样，观感与现在完全一致。

**如果只有一天时间**：做 `ch04-plating`（找素材）+ `ch07-holdout`（自录）两条即可，其余留空。

## 0.2 真正可用的开放素材（已核过授权）

⚠️ **先说一个现实**：中文互联网上那些"锂电池原理"动画，几乎全是同一批素材的互相搬运——
搜狐、网易、化学自习室、钜大锂电等站点上的文字**逐字相同**，源头多为公众号内容，
页面自己也写着"如涉及版权问题请及时联系我们删除"。
**这类素材版权来路不明，放进参赛作品是实打实的风险**（与"原创性与知识产权声明"直接冲突），
而且内容里常出现"电子穿过隔膜"这类错误表述，搬来反而是降级。

**B 站 UP 主的科普视频同理**：哪怕画质好、讲解也准，只要没有作者的书面授权，
下载后自托管就是"未经授权复制他人作品"；只做外链嵌入又断网即失效。
→ 结论：**只用"公有领域 / CC 授权"的素材，其余一律自制。**

## 0.3 动画与科普视频会不会冲突？——这是取舍的总原则

**不冲突。冲突只发生在一种情况：视频在复读动画已经讲清的内容。**

两者在评审眼里是**两种不同的分**，各有各的职责：

| | 网页动画（本作品主体） | 科普视频（补充素材） |
|---|---|---|
| 评审看到的是 | **技术实力与原创性**——自研的实时 3D 交互，这是作品的护城河 | **真实感、权威性、学生的实质贡献** |
| 职责 | 讲"机制"：可交互、可操控、可反复观察 | 补"动画给不了的"：实物长什么样、权威机构原始影像、团队自己的算法 |
| 覆盖范围 | 全部 7 章 + 第 8 章教育设计页 | 只放在 1—3 个关键位置 |

**分工原则一句话：视频只做"网页做不出来的那三件事"。**

1. **真实实拍**——实物到底长什么样（`ch02-teardown`）
2. **权威机构原始影像**——NASA/NREL 同步辐射 X 射线、ORNL 纳米级枝晶生长（`ch04-plating`）
3. **团队自己的算法与结果讲解**——这是"学生实质性贡献"最硬的证据（`ch07-holdout`）

反过来，凡是动画已经能交互演示的（锂离子迁移、CC-CV 曲线、SEI 增厚、三条路线对比），
**再放视频就是拿视频去稀释动画**——评审的第一反应会是"是不是动画不够用才塞视频"。
这几条一律留空。

### 最终取舍（2026-10-15 更新）：8 个视频位，7 个改由自制微动画实现，1 个保留实拍位

**结论先写**：不再等外部视频。8 个位里，有 7 条讲的是**机理**，而机理恰恰是动画比实拍讲得更清楚的
（可控、可反复回看、能标注、能纠正错误说法）。这 7 条已直接做成**页内自制微动画**上线。

| 视频位 | 现在的实现 | 素材 / 依据 | 备注 |
|---|---|---|---|
| `ch03-ion-path` | ✅ **自制微动画** | 电化学基本原理 | 刻意纠正中文网络"电子穿过隔膜"的错误画法 |
| `ch03-cccv` | ✅ **自制微动画** | CC-CV 标准协议 + BS-01 概念设定（1C = 5.0 A） | 曲线形状示意，已常驻声明 |
| `ch04-sei` | ✅ **自制微动画** | 机制库 dL/dt ∝ 1/L，积分即 √t | 归一化相对量 |
| `ch04-plating` | ✅ **自制微动画** | 机制库析锂判据 j_Li > 0 | ⚠️ 若日后拿到 NASA/NREL 实拍影像，可覆盖同一视频位（真实视频优先） |
| `ch05-nasa` | ✅ **自制微动画** | NASA PCoE 原始测试口径 + B0005 逐点实测容量 | 两条参考线口径分开标注 |
| `ch06-methods` | ✅ **自制微动画** | 三条路线的输入 / 输出形态 | 评分条为主观 1—5 档定性评分 |
| `ch07-holdout` | ✅ **自制微动画** | 与第 07 章面板**同源现算**（B0005 前 80 次） | 学生算法贡献的硬证据 |
| `ch02-teardown` | ⬜ **仍留实拍位** | 自己拍 / 录一段剖切或拆解 | 它回答的是"实物长什么样"，动画给不了这一层 |

**为什么这样取舍**（回答"动画和科普视频会不会冲突"）：

- **不冲突，只要分工**：动画答"**机理怎么变**"（可控、可交互、能标注，证明技术能力与科学性）；
  实拍答"**真实世界怎样**"（实物形态、权威影像，证明现实锚点与教育设计）。
- **冲突只在一种情况下发生**：视频把动画已经讲透的内容再复读一遍 —— 那才是重复、稀释原创性。
  因此凡是"机理类"的视频位，一律用动画，不再另找实拍。
- **留下的那一层实拍价值最高的就是 `ch02-teardown`**：整机剖开、卷芯展开的实物形态，
  是纯动画最难替代、评审最容易感知"真做过"的一处。

**这 7 条动画带来的三个实际好处**：

1. **版权零风险** —— 完全自制、逐帧编程绘制，不含任何第三方素材 / 贴图 / 影像。
2. **断网可用** —— 纯前端 Canvas，不依赖任何外部资源，演示现场不怕网络问题。
3. **口径可控** —— 每一帧里出现的数字都能说出出处，都能在第 08 章溯源表里查到；
   纯装饰性粒子的初始位置用确定性伪随机生成，不参与任何数值。

**视觉质量（2026-10-15 晚提升）**：最初 7 条动画里，三条"微观机理"（离子双路径 / SEI / 析锂）
画得更像"示意图"——电极是大片纯色矩形、粒子稀疏。这一轮参照开放科研影像
（NREL 同步辐射 X 射线影像、ORNL 枝晶纳米影像、BESS.engineer 电芯剖面动画）共有的视觉语言重做：

- **电极改成颗粒堆积床**：正极画球形二次颗粒、负极画**石墨片晶**（石墨是片层结构，画成球会误导）；
- **SEI 改成包覆在颗粒表面**的壳（而不是悬在电极上方的一条横带）—— 这是最需要纠正的一处画法；
- **金属锂改成苔状沉积 + 针状枝晶**，并让"锂到底进没进颗粒"通过**颗粒明暗**直接可见：
  正常工况颗粒被逐步点亮、析锂工况嵌锂在较低水平即被迫停止（颗粒保持偏暗）；
- **析锂页补成完整界面剖面**：正极颗粒床 → **多孔隔膜带**（真实隔膜是孔隙率约四成的聚合物膜，
  多孔才是"锂离子能过、电子不能过"的物理原因）→ 电解液（含溶剂分子与穿行的 Li⁺）→ 负极颗粒床；
  窄屏面板只有约 64px 高，四层塞不进去，退化为"隔膜 + 电解液 + 负极床"（与宽屏加层前逐像素一致）；
- **全站电极配色统一**为正极紫、负极蓝（与第 02 章三维模型、第 03 章离子双路径同一套约定），
  修正了早期 SEI / 析锂两页把负极画成紫色的跨场景不一致；
- 曲线类（CC-CV）补了渐变面积填充与网格。
- 所有颗粒 / 枝晶形貌均为**程序生成的示意结构**，口径栏与第 08 章溯源表均已常驻声明。

> **留空仍然安全**：`ch02-teardown` 未就绪时在正式构建里**完全不渲染**，
> 页面上不会出现空白框、占位符或"待接入"字样。
>
> ⚠️ **优先序**：真实视频 > 本站自制微动画。若日后拿到了 NASA/NREL 的同步辐射 X 射线影像，
> 把它放进 `public/media/`，并把 `src/data/videos.js` 里对应那条改成 `status:'ready'` + `src`，
> `VideoSlot` 会**自动优先播放真实视频**，该位上的动画自动让位。二者是互补关系。

### ⚠️ 不要混淆两份视频

| | 页面科普视频 | 参赛演示视频 |
|---|---|---|
| 是什么 | 作品**内部**的教学素材 | 介绍作品**本身**的宣传片 |
| 是否必交 | **可选**（本文档讨论的就是它） | **必交**（竞赛第四条第 6 款） |
| 规格 | 见第 1 节 | 按组委会《作品材料提交规范》，**待索取** |
| 归属 | 本项目代码内（`public/media/`） | 独立文件，随报名材料提交 |

**两条线互不影响**：页面视频做不做、做几条，都不改变"演示视频必须单独做一条"这件事。
演示视频是另一条独立任务线，且优先级更高（它是硬性必交材料）。

## 1. 统一技术规格（所有视频都要满足）

| 项目 | 要求 | 说明 |
|---|---|---|
| 分辨率 | **1920×1080（16:9）** | 页面播放器按 16:9 容器排布，其他比例会留黑边。竖屏素材不采用。 |
| 帧率 | **25 或 30 fps** | 录屏用 30 fps 更稳。不要 60 fps（体积翻倍，收益为零）。 |
| 编码格式 | **MP4（H.264 + AAC）** | 兼容性最好。不要用 H.265/HEVC，部分浏览器播不了。 |
| 码率 | 1080p 建议 **6—10 Mbps** | 再高没意义，再低会糊。 |
| 单文件大小 | **≤ 60 MB** | 页面是静态站点，视频会随站点一起分发；太大首屏会拖慢。超了请告诉我，我改成分段/延迟加载。 |
| 时长 | **30 秒 — 120 秒**（各条有具体要求） | 这是"补充讲解"的定位，不是正片。超过 2 分钟注意力就跑了。 |
| 音频 | **有人声讲解**，音量均值约 -16 LUFS，峰值不超 -1 dBFS | 纯 BGM 无讲解的视频，教学价值会大打折扣。 |
| 字幕 | **必须有中文字幕** | 硬字幕（烧进画面）最省事。必须是中文；专有名词可中英并列。 |
