# BatteryScope V3.3 · 锂电池生命观察站

> 以同一块概念标本 BS-01 为叙事主角，从结构、工作与老化机制，走向 NASA 真实数据、预测方法和可回测寿命基线。

本版重新对照三份需求文档完成核验与优化：BatteryScope 任务书、BatteryScope 改进设计方案、BatteryScope V3 详细修改意见。文档冲突时以最新的 V3 详细修改意见为准；尚未具备数据或模型依据的内容不会包装成已完成成果。

## V3.3 本轮优化

- 参考“蒙韵筑影”的页面层级，重做品牌页头、文字导航、生命进度轨道、首页主视觉、指标区、信息区与页尾；只借鉴结构、留白和节奏，不复制其品牌内容。
- 首页从“三种电芯并排”改为同一观察对象 BS-01，并明确它是概念标本，不是 NASA B0005 的实体数字孪生。
- 全站主色收敛为深蓝黑底 + 霓虹蓝/青；减少无意义辉光和边框堆叠。（早期版本曾试过"近黑绿 + 翡翠色"方案，已弃用，全部回到深蓝。）
- 数据实验室新增“数据可信度说明”抽屉，公开数据源、字段、qRef、SOH 公式、筛选与编号边界。
- 修正双电池工况说明：四块电池的放电截止电压并不相同，不能把曲线差异全部归因于个体离散。
- 80% 统一表述为“教学参考线”，不再直接等同于报废或统一 EOL 标准。
- 当前游标、单步、点击吸附和回放均落在真实数据记录点；故事模式只跳转 5 个关键节点。
- 补齐 18650“热缩膜标签”热点词条；播放、暂停、复位、单步等改用统一 SVG 图标。
- 修复首页环境读数计时器切页后未销毁的问题；构建改用 Sass modern compiler API。

## V3.3.1 交付前打磨（本轮）

- **修掉"点导航跳不动"的真因**：dev server 与离线预览服务同时监听 5188。Windows 下 `0.0.0.0:5188` 与 `127.0.0.1:5188` 可以并存，同一页面里不同请求被两个服务轮流处理 —— 入口拿到 dev 的 index.html，懒加载 chunk 却落到只认构建产物的离线服务上，404 导致 vue-router 中止导航。dev 固定改到 5173，离线服务加禁缓存响应头。
- **三个细看页统一放开视角**（结构 / 原理 / 老化）：滚轮缩放 + 右键平移 + 拖拽旋转，并各加一个「重置视角」退路和一键操作提示。取景口径按模型实际尺寸定，避免"滚一格就贴脸"。
- **相机飞行改为手写 rAF 插值**，不再用 `gsap.to(camera.position)`：OrbitControls 每帧 `update()` 会用球坐标把 gsap 写入的值推回去（表现为"点了重置回不到原位"）；且 gsap 的 ticker 在页面被节流时会把每帧增量钳到 33ms（表现为"点了没反应"）。实现集中在 `src/three/cameraFly.js`，三页共用；用户一上手拖动就自动放弃程序化飞行。
- **修复结构页引导线不可见**：`<svg>` 是替换元素，只写 `position:absolute; inset:0` 不会撑开它，会退回 300×150 固有尺寸；而引导线坐标是按舞台像素空间算的，整条线落到视口外被裁。
- **修复一批"类名跨组件失效"**：`card-panel`、`switch`、`icon` 等类名只定义在某个页面的 `<style scoped>` 里，别的页面用同名 class 会拿到一个没有样式的空壳。已把共用项提到 `base.scss`，页面专有的就地补上；并留了 `scripts/audit-classes.cjs` 随时复查。
- **清掉数据库页残留的旧主题色**：数据说明抽屉的底色还是上一版翡翠绿的 `rgba(7,20,17)`，与全站深蓝撞色。
- **修复预测页步骤卡**：未激活步骤整卡 `opacity: 0.45` 叠加缺失的卡片底色，文字几乎融进背景；改为卡片常显、用虚线边框区分"还没轮到"。
- **修正文档**：README 与启动脚本里的 dev 端口统一为 5173，并写明三个启动脚本的端口分工。

完整“需求—实现—证据—状态”矩阵见 docs/需求对照与优化报告.md。

## 一、运行方法

### 方法 A：联网开发版

前提：安装 Node.js LTS。Node.js 装在 C:\Program Files\nodejs\ 完全正常，项目依赖会安装在当前项目的 node_modules，不需要全局安装 Express、Vite 或 Vue。

Windows 可直接双击：

~~~text
启动网站.bat
~~~

首次运行会从 https://registry.npmmirror.com/ 安装依赖，然后打开 http://localhost:5173。

也可在项目目录执行：

~~~bash
npm install --no-audit --no-fund
npm run dev
~~~

看到 VITE ... ready 和 Local: http://localhost:5173/ 即启动成功。终端必须保持打开；按 Ctrl+C 停止。

> 端口分工（三者不可重复，否则会出现"首页能开、点导航跳不动"）：
> 5188 = 启动离线版.bat（跑 dist）｜5173 = 启动网站.bat（dev，改源码用）｜5189 = 启动静态版.bat（vite preview）。

### 方法 B：免安装依赖的离线预览

双击 启动离线版.bat。它仅使用 Node.js 托管已构建好的 dist/，不会执行 npm install。

### 方法 C：构建后预览

~~~bash
npm run build
npm run preview
~~~

若指定 5189 端口：

~~~bash
npm run preview -- --port 5189
~~~

### 网络或权限异常

先在项目目录检查：

~~~bash
npm ping
~~~

若镜像不可达，可切换官方源：

~~~bash
npm config set registry https://registry.npmjs.org/ --location=project
~~~

若官方源超时，可切回：

~~~bash
npm config set registry https://registry.npmmirror.com/ --location=project
~~~

EPERM 且路径位于 C:\Program Files\nodejs\node_cache 或 node_global，表示 npm 缓存/全局目录权限配置有问题，不是 Node.js 装在 C 盘的问题。运行本项目无需 npm install express -g。

## 四、人工验收方法

建议使用 Chrome/Edge，浏览器缩放 100%。

1. 依次进入 01—07，核对顶部短章名、当前对象、页内 Chapter 和底部导航一致。
2. 在第 2 页依次切换 18650、21700、方形和软包；每种至少点击 6 个热点，确认详情不为空。
3. 在第 3 页确认播放速度只改变动画节奏，倍率才改变通量/功率等物理读数。
4. 在第 4 页连续播放三轮并往返切页，确认播放不会越来越快，图表没有 Unknown series。
5. 在第 5 页任意选择两块电池对比；检查两条曲线都不被截断，截止电压差异被明确显示。
6. 打开“数据说明”，确认 qRef、SOH、筛选、重编号和三类徽标均有解释。
7. 在第 6 页切换三条路线；页面不得显示未经训练的固定精度或 RUL。
8. 在第 7 页运行、复位、再运行 10 次；结果和图表应稳定出现。
9. 分别用约 1440×900、1920×1080、390×844 检查无横向溢出、遮挡或不可点击区域。
10. 连续运行约 10 分钟并打开浏览器控制台；目标是无 error、主要交互不卡死。

### 移动端（手机浏览器）

本作品为**手机 / 电脑双端**自适应：桌面（≥768px）为实验台布局，窄屏（<768px）改为单列流式布局。

- **顶栏**换成翻页式：`‹ 上一章　当前章　下一章 ›`，点中间那块展开全部七章目录。
- **三页 3D 场景**（结构 / 原理 / 老化）窄屏把读数、图例、控制按钮从"叠在画面上"
  改为依次排到画布下方，画布不再被遮挡；手势为**单指旋转 · 双指缩放与平移**，
  并保留「重置视角」按钮。
- 触摸目标均 ≥ 44px、正文字号不低于 12px；滑杆加大了可点高度。
- 手机上可直接用浏览器地址栏打开交付预览地址；也可在电脑浏览器开 DevTools 的
  设备模拟（如 390×844）查看同一布局。

## 五、科学口径

- BS-01：概念教学标本，用于结构、原理与机制可视化。
- NASA B0005/B0006/B0007/B0018：当前交付中的真实放电容量/SOH 记录。
- 1.4 Ah：NASA 实验停止判据；80%：本站教学参考线，两者不能混同。
- 环境沙盘：固定规则驱动的定性趋势演示，不输出精确寿命。
- 第 7 页：Theil–Sen 稳健趋势 + 单调指数外推的可回测基线，不是 PINN。
- PINN：已完成方法解释和接口边界，真实训练、跨电池验证仍属于后续研究。

`scripts/` 里的工具（都是可重复运行的，不是一次性脚本）：

| 脚本 | 用途 |
|---|---|
| `shots.cjs` | 对着指定地址批量截 7 页演示图（1600×1100） |
| `diagnose-nav.cjs` | 真实点击 7 个导航项并监听网络失败 / JS 异常，一句话区分"代码坏了"还是"服务或缓存坏了" |
| `verify-look-views.cjs` | 三个细看页的视角交互实测（滚轮缩放 / 右键平移 / 拖拽旋转 / 一键重置），直读相机数值判断是否真的生效 |
| `verify-app.cjs` | 全站冒烟：逐页加载并检查关键元素 |
| `audit-classes.cjs` | 扫描"模板里用了但样式从未定义"以及"只在别的组件 scoped 块里定义"的类名 |

> `verify-look-views.cjs` 依赖 Vue 开发构建挂在 DOM 上的组件实例钩子，必须跑在 dev server（5173）上；`shots.cjs` 则对着构建产物（5188）截。

- 自动化测试不能替代 1080p 长时间帧率实测；参赛录屏前仍需执行人工验收第 9、10 项。
