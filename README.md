# BatteryScope V3.3 · 锂电池生命观察站

> 以同一块概念标本 BS-01 为叙事主角，从结构、工作与老化机制，走向 NASA 真实数据、预测方法和可回测寿命基线。

本版重新对照三份需求文档完成核验与优化：BatteryScope 任务书、BatteryScope 改进设计方案、BatteryScope V3 详细修改意见。文档冲突时以最新的 V3 详细修改意见为准；尚未具备数据或模型依据的内容不会包装成已完成成果。

## V3.3 本轮优化

- 参考“蒙韵筑影”的页面层级，重做品牌页头、文字导航、生命进度轨道、首页主视觉、指标区、信息区与页尾；只借鉴结构、留白和节奏，不复制其品牌内容。
- 首页从“三种电芯并排”改为同一观察对象 BS-01，并明确它是概念标本，不是 NASA B0005 的实体数字孪生。
- 全站主色收敛为近黑绿 + 翡翠色，数据蓝作为辅色；减少无意义辉光和边框堆叠。
- 数据实验室新增“数据可信度说明”抽屉，公开数据源、字段、qRef、SOH 公式、筛选与编号边界。
- 修正双电池工况说明：四块电池的放电截止电压并不相同，不能把曲线差异全部归因于个体离散。
- 80% 统一表述为“教学参考线”，不再直接等同于报废或统一 EOL 标准。
- 当前游标、单步、点击吸附和回放均落在真实数据记录点；故事模式只跳转 5 个关键节点。
- 补齐 18650“热缩膜标签”热点词条；播放、暂停、复位、单步等改用统一 SVG 图标。
- 修复首页环境读数计时器切页后未销毁的问题；构建改用 Sass modern compiler API。

完整“需求—实现—证据—状态”矩阵见 docs/需求对照与优化报告.md。

## 一、运行方法

### 方法 A：联网开发版

前提：安装 Node.js LTS。Node.js 装在 C:\Program Files\nodejs\ 完全正常，项目依赖会安装在当前项目的 node_modules，不需要全局安装 Express、Vite 或 Vue。

Windows 可直接双击：

~~~text
启动网站.bat
~~~

首次运行会从 https://registry.npmmirror.com/ 安装依赖，然后打开 http://localhost:5188。

也可在项目目录执行：

~~~bash
npm install --no-audit --no-fund
npm run dev
~~~

看到 VITE ... ready 和 Local: http://localhost:5188/ 即启动成功。终端必须保持打开；按 Ctrl+C 停止。

### 方法 B：免安装依赖的离线预览

双击 启动离线版.bat。它仅使用 Node.js 托管已构建好的 dist/，不会执行 npm install。

### 方法 C：构建后预览

~~~bash
npm run build
npm run preview
~~~

若指定 5189 端口：

~~~bash
npm run preview -- --port 5189
~~~

### 网络或权限异常

先在项目目录检查：

~~~bash
npm ping
~~~

若镜像不可达，可切换官方源：

~~~bash
npm config set registry https://registry.npmjs.org/ --location=project
~~~

若官方源超时，可切回：

~~~bash
npm config set registry https://registry.npmmirror.com/ --location=project
~~~

EPERM 且路径位于 C:\Program Files\nodejs\node_cache 或 node_global，表示 npm 缓存/全局目录权限配置有问题，不是 Node.js 装在 C 盘的问题。运行本项目无需 npm install express -g。

## 四、人工验收方法

建议使用 Chrome/Edge，浏览器缩放 100%。

1. 依次进入 01—07，核对顶部短章名、当前对象、页内 Chapter 和底部导航一致。
2. 在第 2 页依次切换 18650、21700、方形和软包；每种至少点击 6 个热点，确认详情不为空。
3. 在第 3 页确认播放速度只改变动画节奏，倍率才改变通量/功率等物理读数。
4. 在第 4 页连续播放三轮并往返切页，确认播放不会越来越快，图表没有 Unknown series。
5. 在第 5 页任意选择两块电池对比；检查两条曲线都不被截断，截止电压差异被明确显示。
6. 打开“数据说明”，确认 qRef、SOH、筛选、重编号和三类徽标均有解释。
7. 在第 6 页切换三条路线；页面不得显示未经训练的固定精度或 RUL。
8. 在第 7 页运行、复位、再运行 10 次；结果和图表应稳定出现。
9. 分别用约 1440×900、1920×1080、390×844 检查无横向溢出、遮挡或不可点击区域。
10. 连续运行约 10 分钟并打开浏览器控制台；目标是无 error、主要交互不卡死。

## 五、科学口径

- BS-01：概念教学标本，用于结构、原理与机制可视化。
- NASA B0005/B0006/B0007/B0018：当前交付中的真实放电容量/SOH 记录。
- 1.4 Ah：NASA 实验停止判据；80%：本站教学参考线，两者不能混同。
- 环境沙盘：固定规则驱动的定性趋势演示，不输出精确寿命。
- 第 7 页：Theil–Sen 稳健趋势 + 单调指数外推的可回测基线，不是 PINN。
- PINN：已完成方法解释和接口边界，真实训练、跨电池验证仍属于后续研究。
