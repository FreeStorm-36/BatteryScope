## 一、这个作品是怎么做出来的（技术路径）

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Vue 3.5（`<script setup>`）+ Vue Router 4（Hash 模式） | 纯前端静态 SPA，无后端、无 SSR，产物可直接静态托管，评审环境断网也能跑 |
| 构建 | Vite 5 | 开发伺服与产物分包；每条机理微动画走 `() => import()` 独立成 chunk，首屏不带动画代码 |
| 三维 | Three.js 0.169 | 程序化建模 + OrbitControls；共享场景工厂 `src/three/labScene.js`（Bloom、环境反射、DPR 分级） |
| 二维图表 | ECharts 5 | 第 04—07 章的曲线 / 雷达；**损伤指纹雷达为自绘 SVG**（按机制着色，见下） |
| 动画 | GSAP 3（仅免费使用范围）+ 手写 rAF | 相机飞行一律走 `src/three/cameraFly.js`；`gsap.ticker.lagSmoothing(0)` 全局关闭 |
| 样式 | Sass + 设计令牌（`src/styles/base.scss`） | 深蓝科技调；`--green` 只作健康 / SOH 语义色，不作 UI 主色 |
| 数据 | `src/data/nasa/*.json`（NASA PCoE 实测）+ `src/data/index.js`（概念校准表 CAL） | 实测与示意严格分流，见第四节溯源表 |
| 测试 | `npm test`（9 用例）+ `scripts/` 下 CDP 体检脚本 | 逐页检查路由 / 横向溢出 / 关键元素 / 控制台异常 |

**三维建模口径**：1 unit = 10 mm；26650 = r1.30/h6.50（BS-01 采用），21700 = r1.05/h7.00，
18650 = r0.90/h6.50（取自 `src/three/batteryModel.js` 的 `CELL_SPECS`）。外壳按镀镍钢口径
（`0xa9b4c3`，metalness .92 / roughness .3），不是深蓝塑料。全部模型程序化生成，无外部模型文件。

**页内机理微动画（7 条）**：`src/components/anim/` 下 Canvas 2D 逐帧绘制，
场景注册表 `src/data/animations.js`；颗粒 / 片晶 / 枝晶 / 苔状沉积均为**程序生成的
示意结构**（`stage.js` 的 `ball` / `flake` / `dendrite` / `mossyProfile` 等原语），
确定性伪随机（mulberry32）只用于粒子初始摆位等纯装饰，**绝不参与任何数值**。
回测数字唯一入口 `src/data/holdoutCase.js`，页面面板与动画共用，不可能不一致。

**人工智能助手「小锂」**：`src/services/aiAssistant.js`。
默认走**站内知识库检索**（类 RAG：中文二元组 + 同词词典打分，语料来自本作品既有
科普内容，`src/data/assistantCorpus.js`）；预留了远程大模型接口
（`VITE_AI_API_BASE` / `VITE_AI_API_KEY` / `VITE_AI_MODEL`，OpenAI 兼容
`/chat/completions`，检索结果作为上下文注入），未配置时自动回落本地检索。
接口契约见 `docs/AI助手接口说明.md`。

## 二、方法出处（用的是什么方法，为什么用它）

| 方法 | 用在哪 | 是什么 | 为什么用它 |
|---|---|---|---|
| Theil–Sen 中位斜率估计 | 第 07 章退化率估计 | 取所有点对斜率的中位数作为趋势估计，对异常值稳健 | 电池容量序列存在恢复尖峰与测量波动，最小二乘会被这些点带偏，中位斜率不会 |
| 留出法回测（Hold-out Backtesting） | 第 07 章结果检验 | 把一部分历史数据留出、不参与拟合，用模型对其预测并与真实值比对 | 这是检验"外推能力"的基本手段，避免用训练数据自证 |
| SOH 容量比口径 | 第 05、07 章 | SOH = 当前放电容量 / 初始额定容量 | 业界最通用、最易与文献对照的口径 |
| 认知层次分类（修订版布卢姆） | 第 08 章知识图谱 | 按识记—理解—应用—分析—评价的层次标注各章知识点 | 用于显性化知识结构，便于教师映射到课程教学大纲 |
| 受扩散限制的 SEI 生长（dL/dt ∝ 1/L ⇒ L ∝ √t） | 第 04 章 SEI 机制 | SEI 增厚使早期老化快、后段趋缓 | 与容量衰减的常见形态一致，便于讲解"为什么早期掉得快" |
| 析锂判据 j_Li > 0（局部电位越过锂沉积平衡电位） | 第 04 章析锂机制 | 界面处锂的到达速率超过固相扩散速率即析出 | 解释"低温 / 快充为什么伤电池"的根因是速率竞争 |

| 依赖 / 素材 | 许可 | 用途 |

| NASA PCoE Battery Dataset | NASA 公开数据（研究与教育用途） | 实测容量数据 |

**模型、贴图、字体、图标与页内动画**：

- **模型**：全部三维模型由本项目程序化生成（Three.js 几何体堆叠），未使用任何外部模型文件；圆柱电芯尺寸按 26650、21700 与 18650 的真实标称尺寸换算（1 unit = 10 mm）。
- **贴图**：未使用外部贴图文件；表面外观由材质参数（金属度 / 粗糙度 / 颜色）直接定义。
- **字体**：仅使用系统字体栈（PingFang SC / HarmonyOS Sans SC / MiSans / 微软雅黑等），未引入任何第三方网络字体，不存在字体授权问题。
- **图标**：界面图标为项目内联 SVG 路径，自行绘制（`src/components/IconGlyph.vue`）。
- **动画**：页内机理动画共 7 条，全部由本项目用 Canvas 2D 逐帧编程绘制，不含任何第三方素材、贴图或影像，不存在素材授权与断网失效问题。动画中出现的数值一律来自仓库内实测数据或在页面常驻声明的概念设定；纯装饰性的粒子初始位置使用确定性伪随机函数生成，不参与任何数值。
- **科普视频位**：8 个视频位默认留空（正式构建完全不渲染）。候选开放素材的授权核验记录见 `docs/教学视频需求清单.md` §0.2；美国政府机构作品（NASA / NREL / ORNL / PNNL）属公有领域，CC BY 4.0 素材（Wikimedia Commons、BESS.engineer）署名即可用。

## 五、数据真实性承诺（一句话口径）

- 图表要么来自 NASA PCoE 实测，要么在页面常驻标注"示意 / 定性 / 概念模拟"；
- 禁止用 `Math.sin/exp` 之类凭空造曲线充当数据；
- 确定性伪随机只用于装饰，不参与任何数值；
- 新增可视化先登记 `provenance`，登记不出来就不上线。
